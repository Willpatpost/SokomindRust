Import / edit a puzzle

O wall · R robot · X box · S goal. Other uppercase boxes match lowercase goals. O, R, S and X are reserved, so o, r, s and x are not goals. Spaces are floor.

Import a route

Apply U/D/L/R moves from the start of this puzzle. You can undo to study any position.

How to play

Push every box onto its matching goal. You can push one box at a time, but you cannot pull. Use arrow keys or WASD (Z undoes), swipe on the board, or the buttons.

Progress stays in this browser.
